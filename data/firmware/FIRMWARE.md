# Дампы прошивок клавиатур

Директория для бэкапов прошивок поддерживаемых клавиатур (справочная информация
для реверс-инжиниринга протокола и восстановления устройств).

> Для работы Keyboard-Center дампы **не нужны** — программа общается с клавиатурой
> по HID, прошивка уже внутри устройства. Дампы полезны только для:
> - восстановления «закирпиченной» клавиатуры через ISP-перепрошивку;
> - сравнения ревизий прошивок;
> - реверс-инжиниринга (поиска скрытых команд в машинном коде).
>
> Прошивки проприетарные (AULA / BY Tech). Распространение — на усмотрение
> владельца репозитория.

## Состав

| Параметр | Значение |
|---|---|
| Устройство | AULA F75, ревизия «BY Tech Gaming Keyboard» |
| VID:PID | `258A:010C` (USB, проводной) |
| Контроллер | SinoWealth SH68F90 (BYK916), 8051 |
| Формат файла | Intel HEX (3841 строк) |
| Размер прошивки | 61 440 байт (0xF000) |
| MD5 данных прошивки | `564524ecd3aed509c3bba432f0398aca` |
| MD5 файла | `e2b5c9ad159962302d994a501ce4bb63` |
| Инструмент | `sinowisp` v2.1.0 (carlossless) |
| Команда | `sinowisp read -d aula-f75 --reboot false` |
| Дата снятия | 2026-09-11 |
| Статус | бэкап, без модификаций (записей не выполнялось) |
