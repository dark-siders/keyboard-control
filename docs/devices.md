# Поддерживаемые устройства и статус

Проект поддерживает механические клавиатуры **AULA F75 / F99** и **Ajazz AK820 Pro** в режимах USB и 2.4G. Bluetooth закрыт по решению владельца.

## VID/PID

| Устройство | Режим | VID:PID |
|---|---|---|
| **Ajazz AK820 Pro** | USB + 2.4G (основная ревизия) | `0C45:8009` |
| | USB + 2.4G (вторая ревизия) | `0C45:800A` |
| | USB + 2.4G (сток fw v1.14) | `0C45:8099` |
| | **2.4G-донгл** | `0C45:FDFD` |
| | BT | `0C45:FEFE` |
| **AULA F75** | USB | `258A:004B` |
| | 2.4G | `258A:004C` |
| | BT | `258A:004D` |
| | USB (ревизия «BY Tech») | `258A:010C` |
| **AULA F75 (2.4 GHz)** | 2.4G-ресивер Compx | `3554:FA09` |
| **AULA F99** | USB | `258A:004E` |
| | 2.4G | `258A:004F` |
| | BT | `258A:0050` |

> **F99 и F75 делят один 2.4G-ресивер** `3554:FA09`. VID/PID зависят от ревизии — реальные значения смотрите через `lsusb` / `udevadm monitor`. F75 и F99 могут делить и USB-PID `258A:010C` — истина в `kbc info` (модель из PSD: `0xA4` = F99).

## Статус устройств

| Устройство | USB | 2.4G | BT | Статус |
|---|---|---|---|---|
| AULA F75 | ✅ Полная | ✅ Полная | 🚫 закрыто | **есть железо, работает** |
| AULA F99 | ✅ Работает | ✅ Работает | 🚫 закрыто | **драйвер готов, работает на USB+2.4G (проверено на чужом железе; keymap write / RGB flash / poll/debounce/sleep — открыто)** |
| Ajazz AK820 Pro | 🟢 подсветка/время/сон · 🟡 per-key и заряд | ✅ донгл `0C45:FDFD`: подсветка/эффекты/время/батарея через протокол ресивера `0xFF60` (сон по 2.4G — `Unsupported`) | 🚫 закрыто | **проверено на живом железе 2026-11-16: подсветка (20 режимов), время и сон через `0xFF13` (USB); через донгл — подсветка/эффекты/время (order 0x05/0x0C), сон (0x07) на ревизии донгла не применяется; per-key (`0x23`/`0x20` USB) и заряд (USB `0x20 0x01`, донгл `0x20`) реализованы по реверсу; заводская base-раскладка захардкожена из установщика (`data/ajazz/rgb-keyboard.xml`); макросы (`0x19`/`0x15`) перенесены на `0xFF13` и доступны через `kbc macro --set` (код готов, живой записи ещё не было; чтения макросов нет, кэш живёт до перезапуска процесса); keymap (`0x11`/`0x27`) всё ещё на мёртвом `0xFF68`; per-key по донглу (`0x14`) — задел; TFT портирован на control `0xFF13` + data `0xFF68` с ACK на чанк (hardware-verified на `0C45:800A` по PR `Beattrey/ajazz-ak820-config#2`; на 8009 live-записи ещё не было)** |

> **BT (Bluetooth) закрыто** по решению владельца: подключение по Bluetooth не поддерживается, батарея по BT не читается. Единственный живой канал батареи — 2.4G-ресивер. VID/PID для BT в таблице выше оставлены как идентификаторы устройств.

> **Есть физически у владельца:** **AULA F75** (USB, ревизия «BY Tech Gaming Keyboard» PID `0x010C`) + 2.4G-ресивер `3554:FA09`; **Ajazz AK820 Pro** (`0C45:8009`, USB, на Fedora-машине) — проверен живьём по control-каналу `0xFF13`. **AULA F99** проверена на чужом железе — USB + 2.4G работают; keymap write / RGB flash / poll/debounce/sleep ждут live write-тестов. Read-only диагностика `kbc ajazz-diag` готова, но ходит в wsclx `0xFF68` — на ревизии 8009 он не отвечает, поэтому дамп вернёт `*_error=Protocol` (это ожидаемо; см. [ajazz-guide.md](ajazz-guide.md), раздел A).

## Работа с несколькими моделями

Сканер (`kbc list`) находит все поддерживаемые устройства сразу. Владелец держит подключёнными одновременно:

```
AULA F75 (2.4 GHz) 3554:FA09   # 2.4G-ресивер (hidraw0)
AULA F75            258A:010C   # USB, «BY Tech Gaming Keyboard»
```

> Ресивер `3554:FA09` отвечает на команды только если клавиатура **не спит на линке** — перед `kbc battery` / `kbc rgb` нажмите клавишу. Пока клавиатура спит, ресивер отвечает константным блоком на любой read.

## Ограничения

- **Статический цвет по USB** — однотонная статика у AULA — host-эффект приложения и живёт, пока приложение запущено; в память USB-конфига пишутся только аппаратные эффекты прошивки. На 2.4G-ресивере Solid (однотонный) с версии 0.6.1 пишется в память и проверен на железе.
- **Батарея** — по USB канал заряда у AULA отсутствует (данные о заряде по проводу не передаются) — в GUI/CLI это честно объясняется. 2.4G — работает; **BT — закрыто решением владельца** (подключение по Bluetooth не поддерживается, заряд по BT не читается). У Ajazz заряд реализован, но живой проверки ещё ждёт.
- **AULA remap** — для **F75 (USB) ремап реализован и подтверждён на железе**: протокол (512-байтная таблица, слои Default/FN1, защита Fn #53 и F1–F12, трейлер `5A A5`), карта слотов «слот ↔ физическая клавиша» (подтверждена дампом заводской таблицы), CLI `kbc remap` (клавиша→клавиша `--to`, медиа `--media`, **модификаторы `--modifier 0..7` (0xE0–0xE7)**). Нюансы: **запись ремапа применяется прошивкой сразу к обоим слоям (Default и FN1)** одним blob'ом — достаточно одного `--layer 0`; **после любого тестового ремапа (= особенно `--modifier`) обязательно проверять откат readback'ом** (`kbc remap <pid> --list | grep <слот>`), т.к. запись может «молча не примениться»; тестовые модификаторы писать только на неиспользуемые слоты (6, 23, 29, 41, 47, 65, 71, 90–126), а не на рабочие клавиши. Для **F99** канал ремапа не ревёрснут; для Ajazz — реализован в драйвере (по wsclx), но на ревизии `0C45:8009` канал `0xFF68` не отвечает, поэтому ремап там пока недоступен. По реверсу официального ПО keymap Ajazz живёт на рабочем `0xFF13` (`0x11` base / `0x27` Fn, 576 Б на слой) — это и есть путь к рабочему ремапу (этап 3); **чтения keymap нет**, поэтому перед первым remap нужен авто-бэкап. Заводская base-раскладка (81 клавиша) уже захардкожена из официального установщика (ассет `data/ajazz/rgb-keyboard.xml` → `factory_keymap_ak820()`), заводского Fn-слоя в установщике нет.
- **Ролик/энкодер не настраивается** — у F75 ролик аппаратно жёстко закреплён за громкостью (команды переназначения в протоколе нет), у **AULA F99 энкодера/ролика НЕТ** (подтверждено живой диагностикой), у Ajazz AK820 Pro он firmware-fixed (Volume/Mute). GUI больше не предлагает настройку ролика.
- **Screen Manager** — только для Ajazz AK820 Pro. Загрузка идёт через control `0xFF13` + write-only data `0xFF68`: статика — `IMAGE_CFG sub=0x02` → 9×4096 б → `FINISH 0xF0`; GIF — 256-байтный заголовок, `sub=0x03` → чанки → `SAVE 0x02`, до 20 кадров. ACK каждого чанка обязателен, при его отсутствии передача прерывается без финальной команды. Протокол hardware-verified на `0C45:800A` (PR `Beattrey/ajazz-ak820-config#2`); на ревизии `0C45:8009` сначала нужен живой write-тест. По 2.4G TFT остаётся `Unsupported`.
- **Сон по 2.4G (Ajazz)** — order `0x07` донгла отдаёт эхо, но на ревизии владельца не применяется → честный `Unsupported`; сон работает по USB (`0xFF13`). Per-key/keymap/макросы/TFT по донглу тоже `Unsupported` (донгл не релеит данные ответов).
